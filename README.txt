# Gibi online Osasco Express - confirmação direta na planilha

Correções aplicadas:
- Não envia WhatsApp.
- Não abre WhatsApp.
- Última tela pede apenas Nome, Sobrenome e Telefone.
- Nome, sobrenome e telefone são obrigatórios.
- Botão único: Confirmar leitura.
- Ao confirmar, envia linha para a planilha via Apps Script.
- Coluna Leu recebe SIM.
- Se SHEET_WEBHOOK_URL estiver vazio, mostra aviso de planilha não conectada.
- 10 telas de gibi + 1 tela de confirmação.
- Imagens ocupam o máximo do celular sem corte.
- Setas laterais no centro.
- Segunda dobra com resumo, site e telefone.
